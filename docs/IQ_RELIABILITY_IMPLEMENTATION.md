## 运行行为

- Responses 解析器 v4 按索引和消息ID收集有界完成消息，在成功终态缺少输出时补齐。重复消息幂等，冲突身份、内容、角色、阶段或失败终态拒绝判分；仅delta、reasoning、commentary和拒答不能成为有效答案。保留旧兼容协议允许终态消息省略phase/status的规则。
- 零字节、缺少完成事件、缺少最终消息、最终文本为空和无法提取数值分别归因。结构诊断包含完成消息数、终态项数、忽略项数及类型、答案来源、首字节及总耗时，正文和凭据不进入诊断。`ignored_types`使用固定类型词表并有长度上限，包含于诊断下载。
- 网络、超时、流读取中断、429和502/503/504最多补试一次；答错、空输出、判题失败及配置错误不补试。插件内部次数不可见时保持一次调用。HTTP检测禁用可重放请求体及隐式传输回退。
- 两次尝试共享账号、题目和模型配置版本；等待持久化为 `retry_wait` 并释放租约和业务名额。重新领取仍验证健康、预算和配置，取2～5秒抖动、Retry-After和共享组冷却的最晚时间。整轮限时为 `2 * timeout_seconds + 30` 秒。超过截止时结束当前轮，保留下次允许时间。
- 每次已登记且可能发出的尝试单独计预算；明确未发送可退还预算并单独计数。已发送尝试崩溃不重放，未发送预留可重新领取。子记录有 `(result_id, attempt_no)` 和租约唯一约束，尝试编号只能为1或2。
- `status` / `reason` 保存最后有效判定，`last_valid_at` 表示其时间；`last_run_status` / `last_run_reason` 保存最近完成轮次结果。网络或协议失败不使降智恢复；有效答对或管理员关闭检测才解除该限制。配置/凭据修订使旧判定失效，正常令牌轮换沿用旧判定。
- 空输出及协议故障按同配置连续计数：第三轮后30分钟，后续最长60分钟，届时只允许一个恢复探测。硬认证、余额、权限和明确参数错误暂停，处理后使用现有恢复入口。
- 默认新建配置为5分钟、120秒、每天576次；已有1/15分钟等配置和派生/显式预算保留。全局执行并发仍为2。完成及延期唤醒当前实例，跨实例5秒扫描兜底，按最早到期领取。

## 数据及管理员界面

迁移245仅追加尝试表、小时统计表、索引和触发器，并替换设置函数；历史迁移及其checksum保留。默认值变更只影响新建。升级仅从同配置版本、已完成且有效的保留记录恢复判定，无可靠记录时为未知。

最近三轮包含各自最多两次尝试，删除父记录时级联清理尝试。小时统计保存30天，不保存回答正文；记录 `sent`、`not_sent`、`attempt`、`round`、`deferred`、`retry_wait`、`recovered`、排队时间及累计5/15/30/60秒桶。统计清理由领取事务驱动，停用整个工作者后不会后台自行清理，恢复领取后清理过期项。

诊断下载格式升级为 `{ "version": 2, "rounds": [...], "hourly": [...] }`，外部解析程序应适配；不再只是历史诊断数组。有效回答率应以有效 `round` 数 / 全部结束 `round` 数计算，聪明和降智都算有效。`sent - not_sent` 表示保守计费尝试口径；不是供应商账单。硬暂停、预算不足、满载等待和供应商故障分别展示，不能从总成功率中隐藏供应商失败。

界面分开展示最后有效判定及其时间、最近轮次结果、等待/暂停原因和补试时间；重试等待禁止重复点击立即检测。记录仍三轮，尝试细节可折叠，显示预算覆盖不足和持续满载容量提示。旧记录没有尝试或诊断时可正常展示。
