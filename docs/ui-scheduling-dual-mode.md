# 双模式调度界面说明

目标源码：artifacts/scheduling-optimization-20260928/dual-mode-20260929/work。验收日期：2026-09-29。

## 使用方式

在系统设置的「网关」页顶部选择 Sub2API 原版或可控智能调度，再点「应用模式」。当前生效项有「当前使用」标记。这个操作独立于系统设置底部的保存按钮；切换只影响新请求，不改变账号启用状态，正在进行的请求继续完成。

- 原版模式保留上游的低倍率、实验调度、会话保持与权值设置；账号调度权值列仍由原有列显示选项控制。受控调度菜单、暂停入口和分组编辑入口隐藏。
- 可控模式提供独立的分组优先级与权重页面，不显示原版调度权值列，也不请求后台计算这列。旧的全局账号优先级显示为「默认优先级」，仅为尚未保存分组规则的账号提供初始值。
- 直接访问不适用模式的受控调度 URL 会显示当前模式和系统设置入口，不读取分组策略。
- 无法读取模式时不猜测默认值，也不显示未经确认的模式控件。重新读取成功后恢复界面。

历史受控暂停可能已把账号总开关关闭，而旧数据没有保留此前状态。升级和切换模式不会自动打开这些账号。管理员应在账号管理核对「账号总开关」，再根据实际情况启用。新的「暂停与恢复」只影响可控调度；它不会修改账号总开关。

## 分组日常操作

每个分组独立保存优先级和权重，组内所有模型共用。数字越小越先用；同级按权重分配；失败后先尝试同级可用账号，再考虑下一优先级，仍受总尝试次数和等待预算约束。权重 0 停止该组的新分配。

账号可直接行内修改，也可先搜索、勾选，再批量修改。没有选中账号时不展开批量输入。编辑优先级不会立即重排正在编辑的行；保存后才按新优先级排序。每页最多显示 50 个账号，保存仍包含完整分组策略。

页面上方和下方均可保存，也支持 Ctrl/Cmd+S。切组、离开页面、重新读取存在草稿时，会先提供继续编辑或放弃修改。保存冲突保留草稿，禁止直接覆盖；必须明确重新读取。初次分组列表读取失败也可以通过「重新读取」重试。

「当前状态」只显示已经取得的事实。没有逐账号读取控制状态时显示「请求时检查可用性」，不会把账号总开关等同于受控运行状态，也不会虚构正常、可用或实测流量。

## 等待、暂停和诊断

等待区只展示单账号等待和总尝试次数。总等待放在折叠的更多设置中，默认跟随单次等待的两倍。模型名称只用于只读故障排查，不作为规则配置维度。预览会使用明确选择的协议，不发送上游请求。

「暂停与恢复」打开后先显示账号当前控制状态、处理中的请求数，以及分别统计的结果待核对和计费待处理数。主操作根据服务端状态显示暂停或恢复。共享凭据、限定会话、强制停止放在更多选项中，强制停止仍需单独确认。正常暂停不终止已开始的请求，恢复只解除人工暂停，不跳过额度或健康检查。

故障诊断与共用额度/服务配置分层折叠，日常调整无需填写标识。状态读取失败时不把空列表当作没有限制。结果未知的记录仍可核对和登记凭证；本地等待结束不表示远端已经停止或不再计费，也不再描述为必须人工核实后才可释放全部本地容量。后台有界恢复规则由后端验收覆盖。

## 设计约束

本轮使用 taste 的现有项目审计与一致性原则、impeccable 的 Operate/Distill/Clarify/Harden/Craft Floor，以及 GSAP core/frameworks/performance。这是管理员高频操作后台，保留现有 Vue/Tailwind 组件、青绿色强调色、浅深色和布局密度；不采用营销页面布局。设计参数为变化程度 3、动效 2、信息密度 7。

GSAP 仅用于保存成功后 0.2 秒的轻微透明度与位移反馈，不延迟表格出现。prefers-reduced-motion 下跳过动效，Vue 卸载时还原并清理 GSAP context。手机数字输入字号 16px；桌面表格在窄屏转为账号卡片，优先级与权重仍并排。

## 验收边界与复核入口

验收使用真实 Chromium 和生产 Vite 构建，仅在本机 loopback 临时端口提供页面。所有 API 都由 Playwright 的合成数据响应；外部支付脚本请求被本地空响应拦截，不访问生产服务或真实上游。浏览器结果证明界面交互、模式和 API 参数隔离，不替代后端真实数据库、调度重试和线上稳定性验收。

证据位于本阶段 evidence/frontend 和 browser-evidence，脚本为阶段目录的 browser-verify.mjs，设置 fixture 为 settings-fixture.mjs。保留各轮日志；最终结果以 browser-evidence/verification.json、最终完整 suite 的 .exit 文件及对应日志为准。主要截图覆盖 1280px/390px 浅深色、系统模式设置、账号原版权值列以及暂停/诊断。
